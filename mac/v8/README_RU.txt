Dawn of War II: Retribution на Mac вместе с Windows-игроками — патч crossplay_fix v8

Что нового в v8
  Нашли настоящую причину рассинхрона в первые секунды. Windows-версия считает симуляцию на старом сопроцессоре x87
  в одинарной точности (игра сама так настраивает его перед каждым шагом), а Mac-версия — в двойной. Случайные числа
  симуляции (например, «дрейф» бойцов в строю отряда) из-за этого получались разными: угол дрейфа расходился в 24%
  случаев. Отряды на Mac и Windows расползались по-разному, и через 5–8 секунд игра ловила рассинхрон.
  v8 считает эти числа на Mac ровно как Windows (проверено бит в бит против настоящего x87 на 30 тыс. входов).
  Всё из v7 остаётся: математика Windows, вход в лобби Windows-игроков, лог запросов, трасса генератора.

Установка — как раньше
  Распакуй архив где угодно и дважды щёлкни dow2mac/run_vanilla.command (скрипт сам скопирует себя в ~/dow2mac).
  Если macOS не даёт запустить — правый клик → Открыть, или: xattr -dr com.apple.quarantine <папка dow2mac>

Тест (ваниль) — запускать с подробной проверкой синхронизации:
  cd ~/dow2mac && ./run_vanilla.command -sync_high
  Хост на Windows тоже должен быть запущен с -sync_high (стенд так и запущен).
  Зайти в лобби, сыграть: сразу несколько приказов движения, 3–5 минут или до рассинхрона. Выйти (Cmd+Q).
  Логи соберутся в ~/dow2mac/logs_vanilla_<дата>.zip — пришли его.

Через 25 секунд после старта в окне Терминала печатается лог патча. Должны быть строки:
  math: OK - 21 of 21 functions now run msvcr80's code
  randfix: OK - GetRand and GetRandRange compute Windows' x87 (24-bit) values
  randfix self-test: all values bit-exact with Windows x87
Если «NOT patched» или «differ» — пришли окно Терминала.

Сравнение без новой части: DOW2_NORANDFIX=1 ./run_vanilla.command -sync_high
