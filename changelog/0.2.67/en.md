- New add-on UI Scale (Experiment, off by default, Elite and vanilla): the in-match interface - minimap, unit panel, abilities, resources, hero portraits, objectives, the Menu button - gets bigger on large screens. The game itself never draws it larger than its own size, so its UI scale did nothing above 100 % at 1440p and 4K. With the tick on the size follows the screen height (1080p 100 %, 1440p 133 %, 4K 200 %) times the UI scale slider in the launcher's Settings (at 4K 150 % on the slider = 300 %). The main menu and the lobby already grow with the screen and stay as they are.
